What does the input need to look like?

This accepts a manually normalized bundle, not a raw GitHub export. Each PR needs an ID and events with an ID, type and timezone-qualified timestamp. Optional fields include revision, actor, actor_kind, body, check name and conclusion. A merge revision must be the head under review.

    {"id": "m1", "type": "merge", "at": "2026-01-01T11:00:00Z", "revision": "abc"}
