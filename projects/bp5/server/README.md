# Prata backend

The deployed account-based service uses `run.py` and `production.py`. Follow [PRODUCTION-RUNBOOK.md](PRODUCTION-RUNBOOK.md), the [API contract](PRODUCTION-API-CONTRACT.json) and [VPS operations](../deploy/OPERATIONS.md). The authenticated service has isolated learner accounts, guided missions and small speech models; it does not expose the older dialogue-model API.

The notes below describe the preserved **v2 local experiment**. Do not use `app.py` as an internet-facing entry point or treat its historical measurements as validation of the production service.

## Historical v2 local backend

Run from the lab root with `python projects/bp5/server/app.py`. Set `HOST` (default 127.0.0.1), `PORT` (default 8000), `LAB_DATA_DIR`, and `LAB_INSTANCE_ID`. The runtime defaults to `runtime/local-products/bp5`, override with `BP5_RUNTIME`. The runtime includes a local `ffmpeg.exe` decoder; alternatively Python can use `imageio-ffmpeg` or a local `ffmpeg` executable. Never publish the runtime or data directory as static files. The service expects an authenticated access layer if exposed outside localhost; history is shared by everyone who can access the same instance.

The CPU runtime consists of whisper.cpp b5454 + multilingual base, llama.cpp b12032 + Qwen3-4B-Instruct-2507 Q4_K_M, and Piper 2023.11.14-2 + sv_SE-nst-medium. Binaries and model weights are separate from product source. Whisper and whisper.cpp: MIT; Qwen model: Apache-2.0; llama.cpp: MIT; Piper executable: MIT; Swedish NST voice model card identifies its training dataset as CC0. Obtain artifacts from their original project releases/model cards and review their terms before redistribution. The installed ffmpeg binary has its own distribution licence.

Uploads are decoded in a temporary directory, transcribed locally and deleted on normal completion or handled errors. An abrupt process termination can leave a temporary audio file in the data directory; deletion is not secure erasure. Text conversations and explicitly saved evidence are stored in SQLite in `LAB_DATA_DIR`; export and delete are available. The recognition text is fallible and cannot establish pronunciation quality. Model coaching is provisional, transcript-based, and not an official SFI assessment.

On the target i7-1185G7 / 16 GB Windows laptop, one 3.2-second synthetic Swedish phrase took 0.50 s to synthesize and 1.54 s to transcribe warm. One first-run transcript took 40.51 s while downloads and other tasks were running. Two transcripts each contained errors. Short Qwen3-4B replies took 8.55–13.06 s warm in one three-scene test; two contained unnatural Swedish, and an earlier café response invented a nonsensical coffee option while another response was empty. One café reply was appropriate. The model is experimental and not reliable enough to claim validated Swedish tutoring. Llama peak child process RSS was 4,356.7 MiB at 1.5K context; allow a 5 GiB service budget. Models run under one inference lock so they do not peak concurrently, but total service/OS usage adds overhead; budget at least 5 GiB. These measurements are not human-speaker accuracy tests and do not establish quality for extended dialogue. Concurrent users queue, and long recordings take longer. Browser cancellation stops playback/request consumption but may not immediately terminate a running backend inference.

Run `python -m unittest discover -s projects/bp5/server -p test_*.py -v` for API/storage boundary checks. For real voice QA test with consenting speakers and devices, especially mobile Safari; synthetic speech alone is insufficient.

For a repeatable local setup, obtain each pinned archive and model listed in RUNTIME-MANIFEST.json into the ignored `runtime/local-products/bp5` directory, verify each SHA-256 before use, and extract the three Windows archives into `llama`, `whisper`, and `piper` subdirectories respectively. The expected executable paths are `llama/llama-completion.exe`, `whisper/Release/whisper-cli.exe`, `piper/piper/piper.exe`, plus `ffmpeg.exe`. The manifest records the exact voice config, model files, release tags, and licensing caveats. The bundled ffmpeg is a GPL-enabled build; review source and license obligations before redistributing binaries. The voice card declares its underlying dataset CC0 but does not explicitly license the trained voice model.
